# CharInfo editor core provenance

These TypeScript files originate from
https://github.com/uikawinwing/CharInfo-Manager, stable `main` release v0.3.4,
commit `cea832c574794c78870f0547811aa203bc3174df`.

- `characterProfile.ts`: `src/char_info_shared/characterProfile.ts`
- `legacyVisualProfile.ts`: `src/char_info_shared/legacyVisualProfile.ts`
- `remoteMediaUrl.ts`: `src/char_info_shared/remoteMediaUrl.ts`
- `LICENSE`: upstream repository root license, preserved verbatim

The standalone ImgBed editor uses the shared profile format, validation,
managed EJS generation and safe legacy parsing. SillyTavern host APIs and
chat-variable execution are not included. Browser output is generated by
`deploy/worker/build-charinfo-editor.js`; update these sources when syncing
upstream, rather than editing the generated bundle.

Local security and round-trip patches:

- `characterProfile.ts` validates thumbnail URLs even when local sources are
  empty, and excludes the profile JSON payload when detecting duplicate
  `const profile =` assignments.
- `legacyVisualProfile.ts` limits automatic migration to a complete bare static
  call or a standalone ordinary EJS block containing only that call. Mixed code,
  quoted/commented examples and ambiguous additional legacy references are
  rejected without editing the source.

These two files intentionally differ from the pinned upstream commit;
`remoteMediaUrl.ts` and `LICENSE` remain unchanged.
